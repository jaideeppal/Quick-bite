# 🍔 Quick Bite – Food Ordering App

**Developed by Jaideep Pal**

A modern and responsive food ordering web application built using **React.js, Redux Toolkit, React Router, and Tailwind CSS**. Quick Bite allows users to explore restaurants, browse menus, and manage their shopping cart with a smooth and user-friendly experience.

🚀 **Live Demo:** [Quick Bite](https://quick-bite6008.netlify.app/)

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/jaideeppal/Quick-bite.git
```

**2. Navigate to the project folder**

```bash
cd Namaste-react-main
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm start
```

Or:

```bash
npm run start
```

**5. Run tests**

```bash
npm run test
```

*Note: Use the scripts defined in your package.json. The start and test commands may vary depending on your project configuration.*
